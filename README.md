# Sales Prediction using Regression

## Project Overview

This project focuses on predicting sales using a Regression model. The dataset was cleaned, preprocessed, encoded, and used to train a machine learning model. The model's performance was evaluated using standard regression metrics, and the results were visualized for better interpretation.

## Workflow

### 1. Data Collection

* Loaded the sales dataset into Python using Pandas.

### 2. Data Cleaning

* Checked for missing values.
* Handled null values using appropriate techniques.
* Removed unnecessary records.

### 3. Exploratory Data Analysis (EDA)

* Analyzed data distributions.
* Identified relationships between variables.

### 4. Data Preprocessing

* Handled categorical variables.
* Applied encoding techniques.
* Scaled numerical features when necessary.

### 5. Feature Selection

* Selected relevant features for prediction.
* Removed unnecessary columns.

### 6. Train-Test Split

* Split the dataset into training and testing sets using an 80:20 ratio.

### 7. Model Training

* Trained a Linear Regression model using the training data.

### 8. Prediction

* Generated predictions on the test dataset.

### 9. Model Evaluation

The model was evaluated using:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* R² Score

### 10. Visualization

Visualized:

* Actual vs Predicted values

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib

## Results

The regression model was successfully trained and evaluated. The obtained metrics and visualizations provide insights into the model's prediction performance.

## Conclusion

This project demonstrates the complete machine learning pipeline for sales prediction using a Regression model, including data preprocessing, model training, evaluation, and visualization.
